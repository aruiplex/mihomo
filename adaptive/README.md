# Adaptive TCP routing fork

This branch is the authoritative source for adaptive routing. The original prototype.2 patch in aruiplex/proxy is frozen evidence, not a second implementation. The first commit after v1.19.32 imports that patch unchanged. Later commits add local quality lifecycle and candidate automation. The local production proxy remains prototype.2 until a separate prepare/activate/TLS/business acceptance step.

Only Linux/amd64 is currently built and accepted. Candidate and official fixture binaries use CGO_ENABLED=0 and GOAMD64=v1 for portable pure-Go Linux builds; race tests use the runner C toolchain. The pinned Go toolchain, upstream commit and version live in baseline.json; the independently pinned proxy fixture checkout and file digests live in fixtures.json. Offline artifacts include a relative-path manifest.local.json usable after downloading all sibling files. New upstream versions generate new binaries, validation reports, patch digest, source commit and SHA256SUMS. Old prototype digests are never reused.

`validate.py --proxy /path/to/pinned/proxy --output /new/output` runs adaptive/identity race tests, related upstream regressions, verified TLS stream and 60-second idle/outage/reload acceptance, and twelve protocol/no-business-replay runs against a separately compiled unmodified upstream core. Any failure prevents manifest creation. Candidate artifacts may include failure evidence and must only be considered accepted when validation.json is passed. CI does not use production subscriptions, credentials, ports or services.

The default CI builds artifacts. Publishing is an explicit workflow_dispatch with publish=true; all checks rerun for that exact source commit before an immutable prerelease candidate is created. This is not local AI acceptance or activation. Downloaded binaries must be made executable before local prepare. Source identity remains aruiplex/proxy-adaptive for compatibility with the existing managed prototype.

The weekly tracker accepts formal stable semver releases only. It merges into adaptive/upgrade-vX.Y.Z, retains patches, creates a reviewable PR and explicitly dispatches acceptance (GITHUB_TOKEN-created PRs do not otherwise trigger PR CI). Existing open upgrade PRs are reused. Conflicts preserve merge status/diff and source files as an artifact and create one actionable blocked issue, never publish or overwrite the patch. Resolve the issue and review before merging an upgrade. Inherited upstream build/test workflows are disabled in the fork to avoid their release or container publication paths.

## Local quality history

The new version supports `quality-persistence: true` and `quality-ttl: 86400` on an adaptive group. Persistence is opt-in; the deployed prototype.2 does not support it. Records expire even when persistence is disabled. Capacity defaults to 4096 records; TTL accepts 60 seconds through 7 days. A single target's failure stays isolated; only the existing independent-host evidence threshold influences other targets.

Files are private under the core home adaptive-quality directory, named by group hash, schema version 1. They contain target/node labels and must not be uploaded or synced. Node identity hashes the full parsed configuration and provider identity, including credentials without storing the credentials. Same-name configuration/credential/provider changes and removed nodes discard old evidence. Unknown adapter identities do not persist. Group policy changes cold-start conservatively.

Writes are debounced for 500 ms, atomic with file fsync/rename and directory fsync; the newest group owns the checkpoint, so a surviving old stream cannot overwrite a replacement group's state. Up to the last 500 ms can be lost after an abrupt exit. Quality snapshots also checkpoint. Cold startup uses the configured region and bounded attempts when history is absent, expired or corrupt. At most two corrupt files are quarantined; proxy startup continues, with generic persistence status in the quality interface. Event history is not persisted. The owner registry is bounded at 128 paths; evicted groups continue routing but stop checkpointing until recreated.

Do not copy quality state into shared preferences, kernel manifests or remote machines. Current prototype rollback continues to restore its matching binary/config/cache; upgrading to this candidate does not migrate any encrypted business requests.
